# Future Minds — Editorial Website Redesign

## Design direction

The previous public website used a corporate
navy and bright-blue palette, repeated programme
cards, promotional slogans and decorative arrows.

The redesigned public website uses:

- Warm ivory backgrounds
- Charcoal typography
- Restrained olive accents
- Editorial serif headings
- Clear academic language
- Structured programme directory
- Horizontal programme rows
- Stronger content hierarchy
- Simplified header and footer
- Minimal decorative elements

## Pages updated

- Homepage
- About
- Contact
- Global header
- Global footer
- Academic programme directory styling
- Programme details styling
- Admissions styling

## Design principles

1. Academic credibility over aggressive promotion.
2. Clear information over decorative cards.
3. Fewer repeated messages.
4. Restrained use of colour.
5. Accessible responsive layouts.
6. No fabricated testimonials, results or accreditation.
7. Existing authenticated application functionality remains intact.

## Further validation

Review visually on desktop and mobile.
Check keyboard accessibility and contrast.
Verify branding and final copy before deployment.
